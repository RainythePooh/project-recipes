# Project Recipes

Public product-collection tool with browser drafts and named cloud projects. Supports repeated URL batches, deduplication, product and plan-reference previews, source-file downloads and an A4 product-register PDF in the approved style.

## Scope
- Public adapters: Moduplay, Van Ryt Industries, KOMPAN, WillPlay, Active Discovery, Lypa (including lypaproduct.com.au), Landmark Products, Street Furniture Australia and IronClad WA.
- Three reviewed sample records are explicit dated snapshots, with checked supplier files bundled for reliable downloads. Refresh re-reads supplier data and labels the result as automatically collected.
- ChatGPT sign-in provides per-user identity. Named projects are stored in D1 and every read/write is scoped to the authenticated owner. Separate email/password registration is not implemented. Browser drafts are isolated by account, with an explicit import action for legacy guest work.
- PDF generation is browser-side. Raw DWG/DXF downloads preserve the supplier file; preview uses manufacturer plan references, supplier PDFs, embedded DWG thumbnails, or bounded DXF geometry (lines, polylines, arcs, circles and nested blocks; text/dimensions omitted).
- Server resource proxy enforces a fixed supplier-domain allowlist, restricted redirects, HTTPS, file type checks and size/time bounds. It does not bypass login.
- Directory and homepage links open a searchable product/category selector. WillPlay ZIP archives expose their original CAD entries with decompression bounds. Public product PDFs supplement explicit codes and fixing options; unconfirmed fields remain explicit. Street Furniture CAD remains blocked behind its supplier login.

## Pricing and brand update
- Price summary lists all project products in AUD, with editable unit prices and whole-number quantities. Missing prices remain blank and are excluded from the known-price total. Supplier source text is retained separately.
- Values are stored with each product in browser drafts and cloud project JSON; legacy projects initialise quantities to one. Supplier refresh retains project overrides.
- The existing product PDF format is retained; a paginated pricing summary for exported products is appended.
- Website brand, page title and headline are Project Recipes / Create your play&furniture collection.

## Image ZIP and selection update
- Download all images bundles one original main image per collected product into a ZIP, with product-name/code filenames and signature-based extensions. Duplicate names receive suffixes; missing images are listed in a download report. File and archive sizes are bounded.
- Price rows and totals follow checked products, matching PDF selection. Unchecking preserves edited prices and quantities for re-selection.

- Main-image ZIPs use a flat root directory. Supplier support labels are inside the Product URLs input container, separate from the editable URL text.
